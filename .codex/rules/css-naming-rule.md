# CSS Syntax Rules (W3Schools CSS Syntax)

This document defines the required **CSS rule syntax** for generated stylesheets.

Source (only): `https://www.w3schools.com/css/css_syntax.ASP`

## CSS rule structure

- A CSS rule consists of:
  - a **selector**
  - a **declaration block**
- The selector points to the HTML element(s) you want to style.

## Declaration blocks and declarations

- A declaration block is surrounded by **curly braces**: `{ ... }`.
- A declaration block contains **one or more declarations** separated by **semicolons**.
- Each declaration has:
  - a **property name**
  - a **value**
  - separated by a **colon** (`property: value;`).

## Example

```css
p {
  color: red;
  text-align: center;
}
```
